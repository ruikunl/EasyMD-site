macOS Markdown reader and exporter

EasyMD：让 Markdown 预览和导出更一致。

EasyMD 是本地优先的 macOS Markdown 阅读器和编辑器，重点解决 PDF 输出时表格跑版、图片尺寸不可控、预览和导出不一致的问题。

Local-first

为本地文档工作流设计

EasyMD 当前聚焦本地 Markdown 阅读、编辑、实时预览、飞书 DOCX 手动导入和 PDF 导出。渲染资源随 app 打包，不依赖远程 CDN，适合处理不想上传到在线编辑器的文档。

  • 三栏布局：最近文件、大纲、编辑器与实时预览。
  • 支持将飞书导出的 Word DOCX 离线转换为 Markdown。
  • 支持相对路径、绝对路径和 HTTPS 图片。
  • 中英文界面、自动/浅色/深色外观。
  • PDF 默认 A4，可配置方向、页边距和字号。

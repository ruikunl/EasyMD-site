# EasyMD Site

Public website and distribution surface for EasyMD, a local-first macOS
Markdown reader and editor focused on live preview, controllable table and image
layout, Feishu DOCX import, and consistent PDF export.

- Website: https://ruikunl.github.io/EasyMD-site/
- English website: https://ruikunl.github.io/EasyMD-site/en/
- Issues: https://github.com/ruikunl/EasyMD-site/issues
- Releases: https://github.com/ruikunl/EasyMD-site/releases
- Sitemap: https://ruikunl.github.io/EasyMD-site/sitemap.xml

The app source repository remains private for now. Public downloads are attached
to releases in this repository.

## What EasyMD Does

EasyMD is built for local Markdown document workflows on macOS. It combines a
Markdown source editor, live preview, outline navigation, table layout controls,
image resizing and alignment, manual Feishu DOCX import, and PDF export settings
that stay close to the on-screen preview.

The public site is intentionally small and static so search engines can discover
the current download page, release notes, and issue intake page even while the
main application source repository stays private.

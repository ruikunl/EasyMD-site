macOS Markdown reader and exporter

Make Markdown preview and export stay in sync.

EasyMD is a lightweight macOS Markdown reader and editor built for people who care about predictable PDF output, controllable tables, and adjustable local images.

Local-first

Designed for local document workflows

EasyMD focuses on local Markdown reading, editing, and export. Preview resources are bundled with the app, so the core rendering path does not depend on a remote CDN.

  • Three-pane workspace with recent files, outline, editor, and live preview.
  • Relative, absolute, and HTTPS images are supported.
  • Chinese and English UI with Auto, Light, and Dark appearance.
  • A4 PDF export by default, with configurable orientation, margins, and text sizes.
